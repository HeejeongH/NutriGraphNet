EXP-F v2a · Graph Component Ablation (NutriGraphNet) — Genuine Topology Dependence
Critical Finding Removing auxiliary edge types from NutriGraphNet's heterogeneous graph produces real, graded degradation: HR@10 falls from 0.7296 (full graph) to 0.5764 (w/o all auxiliary, −21.0%); removing healthness alone costs −7.2% — the single largest individual-edge-type effect. This is the functional counterpart to EXP-F v1's code-level finding: unlike HFRS-DA (below), NutriGraphNet's message-passing genuinely consumes the topology it claims to model.

EXP-F v2b · NGCF Residual Sensitivity (50% Interaction Dilution)
Since NGCF's propagation never reads auxiliary edge_index directly, a valid ablation instead dilutes 50% of the interactions belonging to auxiliary-connected foods. Result: HR@10 changes only −1.2% to −1.4% across every variant (0.7844 → 0.7732–0.7752) — an order of magnitude smaller than NutriGraphNet's −21.0%, confirming the effect is architecture-dependent, not a dataset artifact.

Bug found & fixed during this run: the first attempt produced Δ=0.000 for every NGCF variant (identical to full graph to 6+ decimal places) — the data-level edge removal step (meant for NutriGraphNet) ran before the dilution logic could inspect the same edges, silently making dilution a no-op. Fixed by skipping that step when the ablation target is NGCF/LightGCN; values above are from the corrected rerun.
EXP-F v1 (Reference) · HFRS-DA Is Mathematically Topology-Invariant
For contrast: removing ANY edge type from HFRS-DA (ingredient, time, food-similar, or combination) produces Δ HR@10 = 0.000 exactly (confirmed <1×10⁻¹⁰ across all 5 folds) — verified via 3 independent checks: (1) health scores non-zero for all 31,458 foods; (2) ablation code correctly zeros edge_index, not edge_attr; (3) reproducible after 3 independent bug fixes. HFRSDAModel.forward()'s NLA branch uses only interaction-matrix embeddings and its SLA branch applies linear(food_emb) only — neither routes messages through auxiliary edge types, making HFRS-DA a topology-invariant embedding model despite its heterogeneous graph framing. HFRS-DA's AUC=0.855 comes entirely from direct embedding lookup + interaction-matrix attention, not from nutritional/temporal graph structure.

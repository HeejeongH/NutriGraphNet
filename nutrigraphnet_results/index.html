Root-Cause Analysis (v0.4)
Two compounding failure modes identified:
(1) Architectural backprop severance: HFRS-DA NLA branch computes scores via direct embedding lookup + interaction-matrix attention only. Neither NLA nor SLA branch routes messages through healthness edges. The NutriLoss health gradient reaches the embedding table but has no path to attention weights governing health sensitivity.
(2) Score distribution mismatch: NutriLoss health_margin was designed for NutriGraphNet's BPR score distribution; HFRS-DA's internal scoring produces a different activation distribution, leaving effective health gradient magnitude near zero.
Practical implication: HFRS-DA provides NO statistical health-alignment guarantee. For clinical deployment, explicit health gradient routing via dedicated convolution along healthness edges is required.
EXP-D · Embedding Dimension Sweep (d = 16 → 256, all models)
MF monotonically improves (0.685→0.753); no saturation. NGCF peaks at d=64 (99.2% of d=256 performance). LightGCN non-monotone (peaks d=32, dips at d=64, recovers at d=256). SGL partial recovery at d=256 (0.270→0.421) but remains 44% below MF. HFRS-DA critical anomaly at d=256: AUC collapses 0.862→0.574 (−27p), HR@10 drops 0.755→0.718.

EXP-F · Graph Component Ablation (HFRS-DA) — Topology Invariance
Critical Finding Removing ANY edge type (ingredient, time, food-similar, or combination) produces Δ HR@10 = 0.000 exactly (confirmed <1×10⁻¹⁰ across all 5 folds). Root cause: HFRSDAModel.forward() NLA branch uses only interaction-matrix embeddings; SLA branch applies linear(food_emb) only. Neither routes messages through auxiliary edge types. HFRS-DA is a topology-invariant embedding model despite its heterogeneous graph framing.

Topology Invariance: Architecture Analysis
HFRS-DA is mathematically topology-invariant: confirmed via 3 independent verification checks:
(1) Health scores non-zero for all 31,458 foods (mean=0.6653) — data is present
(2) Ablation code correctly zeros edge_index (not edge_attr) — ablation is correctly applied
(3) Re-running after 3 bug fixes produces identical results — finding is reproducible

Implication: HFRS-DA's AUC=0.855 comes entirely from direct embedding lookup + interaction-matrix attention, NOT from nutritional/temporal graph structure. Claims of 'heterogeneous graph awareness' require explicit verification that edge types are consumed in forward propagation.

EXP-F v2 (planned): NutriGraphNet (routes messages through all 9 edge types via SAGEConv) + NGCF with 50% interaction dilution for valid topology ablation.

Three Key Findings
🔴 C1 · SGL Augmentation Collapse
SGL achieves HR@10=0.347 vs. MF=0.730 (−53%) at full density.
At 10% density: SGL=0.092 vs. MF=0.344 (−73%).
Graph density (0.040%) is 10× sparser than MovieLens-1M.
Edge dropout removes ~1.26 interactions/user at 10% data → contrastive collapse.
🟡 C2 · MF Ranking Paradox
MF (AUC=0.509) beats all GNNs on HR@10/NDCG@10/MRR despite lowest AUC.
Graph ablation: removing all auxiliary edge types → zero performance change.
GNN over-smoothing + inutile heterogeneous edges explain the paradox.
🔵 C3 · Health Constraint Ineffective
λ_health sweep 0.001→1.0: HR@10=0.7340 for all values (Δ=0.000).
AUC variance < 1.25×10⁻⁷ across four orders of magnitude.
Health loss gradient vanishes — no actual health alignment in practice.

Interpretation
Three possible explanations for zero sensitivity: (1) healthness edge features are linearly separable — model achieves ~zero health loss trivially regardless of λ; (2) health loss is not properly normalized relative to BPR loss — overwhelmed at any λ; (3) attention heads collapse to degenerate fixed-point. Practical implication: HFRS-DA provides no actual health alignment guarantee in this dataset.
EXP-D · Embedding Dimension Sweep (d = 16 → 256, all models)
MF monotonically improves (0.685→0.753). GNNs plateau at d=64–128. SGL partially recovers at high d (0.270→0.421) but remains far below MF/NGCF. HFRS-DA degrades at d=256 (over-fitting with health attention).

EXP-F · Graph Component Ablation (HFRS-DA)
Critical Finding Removing ANY edge type (ingredient, time, food-similar, or all combinations) produces zero change in HR@10, NDCG@10, or AUC. All heterogeneous edges are informationally inert in this model/dataset combination.

What This Means
This finding directly explains the MF Ranking Paradox: since auxiliary edge types provide zero information, GNN message-passing over them adds noise. MF, using only user-food interactions, avoids this noise entirely. This also implies that the NutriGraph-KR graph's value comes entirely from user-food co-occurrence patterns, not from compositional (ingredient) or temporal signals in the current model architecture.
